# 🌴 Kaattike Kuttikal COUSINS TRIP 2026

An interactive, modern, and responsive web portal for family registration and pass generation for the **കാട്ടിലെ കുട്ടികൾ Cousins Trip 2026** 1-Day Resort Get-together.

## ✨ Features

- 👥 **Dynamic Family Member Registration**: Add and remove members with real-time counters.
- 🎯 **3-Way Age Category Segregation**:
  - **മുതിർന്നവർ (Adult)** (>15 Years)
  - **കുട്ടി (8-15 Yrs)** (8 - 15 Years)
  - **കുട്ടി (<8 Yrs)** (<8 Years)
- 🔒 **Interactive Validation & Dynamic Submit Unlock**:
  - Live validation ensuring each member has a valid name and age selected.
  - Requires at least 1 Adult per family group.
  - Submit button dynamically lights up and unlocks only when valid.
- 📊 **Real-time Live Statistics**: Live updates for Total Members, Adults, 8-15 Yrs, and Below 8 Yrs.
- 🎫 **Digital VIP Resort Boarding Pass**: Instant ticket generation with customizable copy/share options.
- 💬 **WhatsApp Direct Group Share**: Formats registrations cleanly for WhatsApp sharing.
- 🔊 **Synthesized Web Audio Feedback & Confetti Celebrations**: Responsive interactive sounds and visual confetti bursts.

## 🚀 Getting Started

Simply open `index.html` in any modern web browser, or run a local static server:

```bash
# Python 3
python3 -m http.server 8000
```

Then visit [http://localhost:8000](http://localhost:8000).
